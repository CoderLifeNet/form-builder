# @coderlifenet/form-postgres

PostgreSQL reference persistence implementation for the form engine.

## Includes

- SQL migrations
- Form draft/publication repository
- Record revision persistence
- Idempotency storage/replay bookkeeping
- Seed script for local development

## Commands

- `npm run db:migrate -w @coderlifenet/form-postgres`
- `npm run db:seed -w @coderlifenet/form-postgres`
